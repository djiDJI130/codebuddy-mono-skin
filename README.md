## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| 🔌 **CDP 零侵入** | 不修改 app.asar、不碰签名、不篡改二进制 |
| 🎨 **12 套主题** | Miku / 原神 / 鸣潮 / 火影 / 龙珠 / 恋与深空 + 更多 |
| 📷 **自定义图片** | 上传任意图片，自动取色生成专属皮肤 |
| 💾 **皮肤常驻** | 跨重启保留，关掉即还原 |
| 📖 **阅读增强** | 90% 半透明阅读底，文字更清晰 |
| 🪟 **毛玻璃效果** | 侧栏/气泡/输入框全带 backdrop-filter |
| 🔄 **一键还原** | 随时恢复原生界面 |

## 🚀 安装

```batch
# 解压 → 双击
一键安装黑白简约皮肤.bat
```
